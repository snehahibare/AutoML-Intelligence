# AutoML-Intelligence
Intelligent AutoML System that automatically detects problem type, selects &amp; tunes best ML model, and explains predictions with feature importance, confusion matrix &amp; ROC curve.


🔗 **Live Demo** → https://automl-intelligence.streamlit.app

Features

-  **Auto Problem Detection** — Classification or Regression 
-  **Smart Model Selection** — chooses the model on the basis of dataset size 
-  **Auto Preprocessing** — missing values, encoding, scaling automatically
-  **Hyperparameter Tuning** — RandomizedSearchCV 
-  **Model Comparison** — visual leaderboard with all model scores
-  **Confusion Matrix** — prediction breakdown
-  **ROC Curve + AUC** — model confidence visualization
-  **Feature Importance** — explains which features matter most
-  **Download Model** — best model as .pkl file

##  Models Used

| Problem | Models |

| Classification | Logistic Regression, Random Forest, Gradient Boosting, SVM |
| Regression | Linear Regression, Ridge, Random Forest, Gradient Boosting |
